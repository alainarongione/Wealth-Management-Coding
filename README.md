# MD Wealth: Wealth Management for Physicians

A Python Shiny app that takes a physician (or physician family) from
"here is who I am" to "here is what I should do with my money, and what could happen."

Physicians are different from typical households: they start earning late (after 7-15
years of training), carry $200k+ of student debt, then see a huge income jump as attendings.
Every module is built around that path.
